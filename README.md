# Астероиды

Двумерная космическая аркада на Python и Pygame. Пилотируйте корабль, уклоняйтесь от астероидов и уничтожайте их ракетами. За каждый сбитый астероид начисляется одно очко.

## Цель лабораторной работы

Продемонстрировать объектно-ориентированное проектирование многофайловой программы, физику с учётом времени между кадрами, взаимодействие нескольких типов объектов на тороидальном поле и тайловую анимацию по спрайт-листу.

## Установка и запуск

Откройте терминал в папке проекта. Подойдёт Python 3.10 или новее. На Windows проект проверен с Python 3.14 и Pygame Community Edition, который устанавливается как пакет `pygame-ce` и импортируется как `pygame`.

```powershell
pip install -r requirements.txt
python main.py
```

Команды должны использовать один интерпретатор. В Windows, если в системе установлено несколько версий Python, можно вызвать установку через `python -m pip install -r requirements.txt`. Все изображения уже находятся в `assets/`.

## Управление

| Действие | Клавиша или кнопка |
| --- | --- |
| Начать или повторить игру | Левая кнопка мыши внутри заставки |
| Вращение против часовой стрелки | ← |
| Вращение по часовой стрелке | → |
| Тяга двигателя | ↑ |
| Один выстрел | Space |
| Выход | Esc или закрытие окна |

Число в счётчике жизней показывает оставшиеся возрождения. После трёх ударов счётчик показывает 0, а корабль ещё может продолжать полёт. Четвёртый удар заканчивает партию. На экране результата видны итоговые очки и оставшиеся жизни. Щелчок по заставке начинает новую партию с 3 жизнями и 0 очков.

## Классы и ответственность

- `Game` обрабатывает события и переходы между `MENU`, `PLAYING` и `GAME_OVER`. Он владеет игровыми объектами, разрешает столкновения и отрисовывает интерфейс.
- `GameObject` хранит позицию, скорости, угол, радиус и изображение. Он реализует общее движение, перенос через границы, отрисовку и круговую коллизию.
  - `Ship` добавляет управление, тягу, сопротивление, выстрелы и возрождение.
  - `Asteroid` задаёт случайные направление, угол и скорости.
  - `Rocket` получает ориентацию при создании и отсчитывает оставшееся время полёта.
- `Explosion` отображает один из общих кадров взрыва по собственному таймеру.
- `Background` управляет двумя слоями космического фона, включая бесшовную прокрутку слоя камней.

## Физика

Позиция и скорость хранятся в `Vector2`. В течение шага времени `dt` корабль добавляет к скорости ускорение, умноженное на `dt`. Вектор тяги поворачивается на средний угол за шаг, а длина скорости ограничивается максимальным значением. При выключенном двигателе скорость умножается на `exp(-SHIP_DRAG * dt)` и обнуляется ниже порога. Позиция меняется на `velocity * dt`, угол — на `angular_speed * dt`. Поворот спрайта каждый раз выполняется вокруг его центра.

Игровой цикл делит длительность кадра на шаги до 1/120 секунды. Это уменьшает вероятность пропуска столкновения, когда быстрая ракета пересекает цель между двумя кадрами. На каждый выстрел действует задержка. Хвост ракеты совмещён с носом корабля. При скорости 650 пикселей в секунду время жизни составляет около 0,86 секунды. Длина траектории равна `min(1000, 700) * 0.8 = 560` пикселям.

## Тороидальная геометрия

Координаты центра корабля и астероидов приводятся к диапазону поля операцией остатка от деления на ширину и высоту. Например, `x = 1003` становится `x = 3`. Скорости и угол сохраняются. Выступающие части этих спрайтов рисуются на противоположной стороне, включая перенос через угол. Ракеты удаляются, как только их центр выходит за границу поля.

Для коллизий по каждой оси используется кратчайшее расстояние с учётом замыкания. Между точками с `x = 998` и `x = 3` горизонтальное расстояние равно 5 пикселям. Квадрат расстояния сравнивается с квадратом суммы радиусов. Тот же расчёт исключает генерацию астероидов в опасной зоне вокруг корабля.

## Столкновения

Сначала проверяются пары «ракета — астероид». При попадании ракета и камень удаляются, в центре камня создаётся взрыв, счёт увеличивается на единицу. Удалённый камень сразу исчезает из списка целей. Затем проверяется корабль: удар уничтожает камень и создаёт взрыв. При наличии жизни корабль возрождается в центре с выключенным двигателем, нулевой линейной и угловой скоростью. Если жизней уже нет, поле и активные эффекты очищаются и показывается заставка `GAME OVER`. Астероиды свободно проходят друг через друга.

## Тайловая анимация

`assets/explosion.png` — прозрачное изображение размером 512 × 512 пикселей. В сетке 4 × 4 лежат 16 различных кадров размером 128 × 128. При запуске игра вырезает тайлы по строкам и хранит их в одном кортеже. Каждый взрыв отсчитывает собственное время. Деление прошедшего времени на 0,038 секунды определяет индекс кадра. Последовательность показывает вспышку, расширение огненного облака, разлёт искр и затухание. Когда индекс достигает 16, объект удаляется. Несколько взрывов могут проигрываться одновременно.

## Дополнительные возможности

- Три размера каменных астероидов с отдельными изображениями и радиусами.
- Мигание и временная неуязвимость после возрождения.
- Отдельный спрайт пламени, встроенного в изображение корабля с тягой.
- Бесшовная отрисовка корабля, астероидов и взрывов на противоположных краях.
