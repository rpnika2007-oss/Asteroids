## Описание проекта

«Астероиды» — двумерная аркадная игра, разработанная на Python с использованием Pygame. Игрок управляет космическим кораблём, уничтожает астероиды ракетами и набирает очки. В проекте реализованы игровая физика, тороидальная геометрия поля и тайловая анимация взрывов.

## Функциональные возможности

### Основной функционал

- Начальная заставка и запуск игры щелчком левой кнопки мыши по ней.
- Управление кораблём с клавиатуры и вращение вокруг его центра.
- Ускорение корабля при включённом двигателе и постепенное замедление после его выключения.
- Смена изображения корабля при включении двигателя.
- Автоматическая генерация астероидов со случайными линейными и угловыми скоростями.
- Стрельба ракетами из носовой части корабля. Время полёта ракеты составляет около 0,862 секунды, максимальная дальность — 560 пикселей.
- Тороидальное игровое поле для корабля, астероидов и ракет. При пересечении границы они появляются с противоположной стороны и сохраняют скорость и направление. Столкновения учитываются и через границу поля.
- Обработка круговых столкновений астероидов с кораблём и ракетами.
- Тайловая анимация взрывов по спрайт-листу из 16 кадров.
- Подсчёт очков и оставшихся жизней, возрождение корабля, завершение и повторный запуск игры.
- Неподвижный звёздный фон и бесшовно прокручивающийся полупрозрачный слой астероидов.

### Дополнительный функционал

- Временная неуязвимость и мигание корабля после возрождения.
- Три размера астероидов с собственными изображениями.
- Ограничение максимальной скорости корабля.
- Минимальный интервал между выстрелами.
- Безопасная генерация астероидов на расстоянии от корабля.
- Расчёт движения с учётом времени между кадрами.
- Одновременное воспроизведение нескольких независимых анимаций взрыва.

## Демонстрация работы программы

### Главное меню

В центре окна отображается заставка ASTEROIDS. Счётчики показывают 0 очков и 3 жизни.

### Игровой процесс

После щелчка по заставке появляется корабль. Игрок управляет им с клавиатуры и стреляет по движущимся астероидам.

### Анимация взрыва

При попадании ракеты астероид исчезает, а на его месте последовательно отображаются 16 кадров взрыва.

### Завершение игры

После столкновения при нуле жизней появляется заставка GAME OVER с итоговым счётом. Последний взрыв воспроизводится до конца. Щелчок по заставке запускает новую партию.

## Установка и запуск

### 1. Клонирование репозитория

Выполните следующие команды в терминале.

```bash
git clone https://github.com/rpnika2007-oss/Asteroids.git
cd Asteroids
```

### 2. Создание и активация виртуального окружения

Выполните команды для вашей операционной системы в папке проекта.

**Windows (CMD)**

```cmd
python -m venv venv
venv\Scripts\activate.bat
```

**Windows (PowerShell)**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**macOS/Linux**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

В активированном виртуальном окружении установите зависимость из файла `requirements.txt`.

```bash
pip install -r requirements.txt
```

### 4. Запуск программы

Запустите игру из папки проекта.

```bash
python main.py
```

### 5. Управление

| Клавиша / действие | Назначение |
| --- | --- |
| Левая кнопка мыши | Запуск или повторный запуск игры при щелчке по заставке |
| ← | Вращение корабля против часовой стрелки |
| → | Вращение корабля по часовой стрелке |
| ↑ | Включение двигателя и ускорение |
| Space | Выстрел ракетой |
| Esc | Выход из игры |

### Назначение основных модулей

| Файл или папка | Назначение |
| --- | --- |
| `main.py` | Точка входа. Управляет игровым циклом, вводом, состояниями игры, столкновениями и интерфейсом. |
| `settings.py` | Содержит настройки окна, физики, генерации астероидов и анимации. |
| `entities.py` | Определяет классы корабля, астероида и ракеты, а также общую логику движения и круговых столкновений. |
| `effects.py` | Загружает изображения, отрисовывает фон и воспроизводит взрывы по кадрам спрайт-листа. |
| `assets/` | Хранит изображения корабля, ракеты, астероидов, слоёв фона и спрайт-лист взрыва. |

Разделение на четыре модуля отделяет управление игрой от моделей объектов, графических эффектов и настроек. Каждый модуль отвечает за свою часть программы, поэтому код проще читать и изменять.

Класс `GameObject` задаёт общие правила движения, переноса через границы и круговых столкновений. От него наследуются `Ship`, `Asteroid` и `Rocket`. Класс `Game` управляет состояниями игры, класс `Background` рисует фон, а `Explosion` воспроизводит тайловую анимацию.

## Пример использования

### Запуск программы

```bash
python main.py
```

### Игровой процесс

1. После запуска открывается главное меню.
2. Счётчики показывают 0 очков и 3 жизни.
3. Игрок щёлкает левой кнопкой мыши по центральной заставке.
4. В центре поля появляется корабль, а на игровом поле появляются астероиды.
5. Игрок поворачивает корабль стрелками влево и вправо, а стрелкой вверх включает двигатель.
6. При нажатии Space корабль выпускает ракету.
7. При попадании ракеты в астероид начисляется одно очко и воспроизводится взрыв.
8. Если при столкновении у корабля остаются жизни, счётчик уменьшается на единицу, а корабль возрождается в центре поля.
9. Если при столкновении счётчик уже показывает 0, партия заканчивается. При трёх начальных жизнях это происходит на четвёртом столкновении. На заставке `GAME OVER` отображается итоговый счёт.
10. Щелчок по заставке начинает новую партию с 3 жизнями и 0 очков.
